# Transmission — AI Buyers Agent (demo)

Buyer-side procurement experience demo. A single-file HTML prototype where a persistent AI procurement agent (**Layla**) does the sourcing, vetting and negotiating for you — you just look and decide.

### 🔗 Live demo
**https://v1ctor2182.github.io/transmission-buyers-demo/**

> First visit auto-launches a short guided tour; replay anytime via **“Take a tour”** in the top bar.

## What it shows
- **Dashboard** — decision-first: *Needs your decision* cards (Approve / hold), reassurance KPIs (saved / advancing / vetted / on-track), and Layla's timestamped worklog.
- **New Sourcing** — Layla drafts the sourcing brief from your project; you confirm, she matches & ranks suppliers.
- **My Projects** — every project, supplier and quote in one place; one-click supplier comparison.
- **Negotiation** — Layla bargains with each supplier on your behalf and shows the price trail; you Accept / push / set a floor.
- **Due Diligence** — auto-vetting of registration, customs, financials and sanctions, with red flags surfaced.

## Run locally
Open `index.html` (identical to `transmission_v5 (1).html`) in any modern browser. No build step — plain HTML + inline CSS/JS. Brand mark is vector SVG (`logo/transmission-tm-icon.svg`).

## Repo notes
